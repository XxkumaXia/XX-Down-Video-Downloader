XX Down —— 使用说明
================================

【软件介绍】
本软件基于开源项目 yt-dlp 打造，把 yt-dlp、ffmpeg 整合成一个图形界面程序，
双击 "XX Down.exe" 即可使用，无需安装任何环境。版本 v1.5。

【主要功能】
2. 画质选择：视频画质（最佳 / 8K / 4K / 2K / 1080p / 720p / 480p / 360p / 仅音频）
3. 音频质量：最佳 / 320K / 256K / 192K / 128K / 64K
4. 下载目录：可自由更改保存位置，并自动记住上次的选择
5. 整包自动更新：检查更新会检测 GitHub Release，有新版时自动下载安装包并静默安装（依次尝试 GitHub 直连、ghfast.top、gh-proxy.com）
6. 更新 yt-dlp：一键检查并更新 yt-dlp 程序
7. Cookies：一键“获取Cookie”，直连运行中的浏览器导出（支持 Chrome/Edge）
8. 微信视频号：下载微信视频号（朋友圈式短视频）分享链接，复用开源引擎 wx_channels_download
9. 抖音：无需 Cookie；但需要 Chrome/Edge 开着远程调试（同「获取 Cookies」里的 autoConnect）。粘贴抖音链接点"开始下载"：以前有一条"无需浏览器"的 API 直连，抖音加了签名风控后已失效（HTTP 403）；现在自动回退浏览器拦截，能拿到标题和一路默认画质（没有全画质列表），选中哪个画质均下这一路
10. 新片场：粘贴 xinpianchang.com 视频链接即可下载（4K 画质需先在浏览器登录新片场）
11. 小红书 / YouTube / B站 / X(Twitter) 等：由 yt-dlp 引擎解析下载
12. 系统通知：下载完成 / 失败时弹出 Windows 通知（显示为 XX Down 本身）

【使用方法】
1. 把要下载的视频链接粘贴到"视频链接"输入框（支持多个链接，每行一个）
2. 选择画质、音频质量、容器格式和下载目录（均在"下载设置"页）
2. 按需勾选"下载自动字幕 / 转 srt / 下载封面"
3. 点击"开始下载"，下方日志会实时显示进度

【微信视频号下载】
本软件内置微信视频号下载能力，复用开源项目 ltaoo/wx_channels_download（首次使用会自动下载引擎）。

使用步骤：
1. 在"微信视频号"面板点"安装/更新视频号引擎"，等待下载完成（仅首次需要）。
2. 点"启动服务"。首次启动会安装根证书并接管系统代理，
   若弹出系统授权提示（UAC）请选择"是"。
3. 打开微信电脑版，进入"视频号"，【双击视频号，把它分离成一个独立窗口】，
   然后在独立窗口里播放任意视频。
   （重要：直接在微信主窗口内播放无法被拦截，必须分离成独立窗口）
   此时视频号页面上会出现下载按钮（首页推荐和详情页都有），
   也可以在"打开视频号面板"里查看。
4. 完成第 3 步后，把视频号分享链接（https://weixin.qq.com/sph/xxxxxxxx）
   粘贴到"视频链接"框，点"开始下载"，由视频号服务在后台下载。
   可点"查看视频号任务"查看进度。

关于系统代理（重要）：
- 视频号服务必须接管系统代理才能拦截视频号页面（代理地址 127.0.0.1:2023）。
- 启动服务前，本软件会先备份你原来的系统代理设置；
  停止服务或退出本软件时，会把代理精确还原回原值。
- 如果本软件异常退出（例如被强制结束）导致代理残留、浏览器无法上网，
  下次打开本软件会自动检测并还原。
- 系统代理被占用期间，其它联网软件会经过视频号服务转发，用完请点"停止服务"。

常见问题：
- 微信 4.1.x 起视频号默认内嵌在主窗口，必须双击分离成独立窗口；
  内嵌播放时页面流量不经过代理，引擎收不到视频信息（报"检测不到视频"）。
- 提示"请先启动服务并打开视频号页面"：说明引擎还没接管到视频号页面，
  请重复第 2、3 步，并保持服务运行。
- 第一次下载失败（singlefile 超时）：多为网络抖动，重试一次即可。
- 视频号文件保存在"下载目录"设置的目录里。

【获取 Cookies（重要）】
新版 Chrome/Edge 对 Cookie 采用"应用绑定加密"，第三方工具（包括 yt-dlp）无法直接读取，
必须让浏览器自己导出。软件采用 Chrome 官方 autoConnect 功能直连运行中的浏览器：

第一次使用（只需一次，约 30 秒）：
1. 打开 Chrome 或 Edge，先登录目标网站（如 YouTube）
2. 地址栏输入 chrome://inspect/#remote-debugging （Edge 输入 edge://inspect/#remote-debugging）并回车
3. 打开 Remote debugging 下的 "Allow remote debugging for this browser instance" 开关（autoConnect）
4. 保持浏览器运行

之后每次使用：
1. 快捷方式：直接在"下载"页点"获取 Cookie"按钮即可（按当前浏览器设置执行）
2. 软件中选"从浏览器获取"→ 浏览器选 Chrome 或 Edge
3. 点击"获取Cookie"
4. 若浏览器弹出"允许远程调试？"，点允许
5. 完成后自动保存为 cookies.txt 并启用

手动方法（备用）：
1. 在浏览器安装扩展 "Get cookies.txt LOCALLY"（Chrome/Edge 商店可搜到）
2. 打开并登录目标网站（如 YouTube）
3. 点击扩展图标 → Export → 保存为 cookies.txt

注意：
- 使用 cookies.txt 前请确认文件不是空的，且是 Netscape 格式（第一行是 # Netscape HTTP Cookie File）
- Firefox 没有加密限制，可直接用"从浏览器获取"读取
- 旧版 Chrome（低于 146）不支持 autoConnect，请升级 Chrome 或使用扩展导出

【Agent 命令行接口（xxdown_cli.py）】
本软件自带一个不带界面的命令行入口，供本地脚本 / AI agent 直接调用。它复用同一套下载引擎、同一份 yt-dlp.exe、同一份 cookies.txt 和同一份设置文件，因此不需要另外安装 yt-dlp，也不需要反复导出 Cookie。

调用方式（在程序目录下执行）：
  python\python.exe xxdown_cli.py <命令> [参数]
  例：python\python.exe xxdown_cli.py download "https://v.douyin.com/xxxx/" --quality 1080p

约定：
1. 标准输出只有一个 JSON 文档，进度和日志走标准错误（加 --quiet 可完全静默）；不弹窗、不启动界面
2. 退出码：0 成功（含命中下载记录直接返回本地路径）、1 有链接失败、2 参数错误、3 环境缺失、130 被中断
3. 界面里设过的下载目录、画质、容器、Cookie 方式默认生效；可用 --dir / --quality / --container / --template / --cookie-file / --no-cookies 临时覆盖，--opt 键 值 可覆盖任意设置项
4. 下载记录存放在 xxdown_index.jsonl（链接 → 本地文件）与 xxdown_archive.txt（按视频 ID 兜底）。已经下过的链接不会再次联网，直接返回本地路径；--force 强制重下，--no-archive 本次不读写记录

命令清单：
  tools                       输出命令清单与可选值（供 agent 自检）
  doctor                      查环境：yt-dlp / deno / ffmpeg / 视频号引擎版本、cookies.txt 域名条目与过期情况、抖音 ttwid 缓存，并给出 problems
  resolve 链接                只解析：标题、时长、可用画质列表，不下载
  download 链接 [链接…]       下载，支持多个链接，自动分流普通站点 / 抖音 / 新片场 / 微信视频号
  history --url 链接          查这条链接是否已下过并给出文件路径；--last N 列最近 N 条
  cookies status | grab | validate     Cookie 状态 / 从运行中的 Chrome·Edge 导出 cookies.txt / 用真实链接校验
  wx status | install | start | stop | tasks     微信视频号引擎控制
  update                      检查并更新内置 yt-dlp 与 deno（更新的就是本地这份文件）

每个命令都可以加 --help 查看完整参数，例如：python\python.exe xxdown_cli.py download --help
注意：双击或运行 “XX Down.exe” 时带的参数只会传给界面，agent 请直接用上面的 python\python.exe xxdown_cli.py 形式调用。

【注意事项】
- 本目录下自带的 cookies.txt 会作为默认 Cookie 文件使用
- 更新 yt-dlp 会自动替换本目录下的 yt-dlp.exe
- 访问 YouTube 等境外网站时，需要自备网络环境
- 软件设置会自动保存到本目录下的 ytdlp_gui_settings.json

【附带文件说明】
- yt-dlp.exe     下载核心引擎（可被"更新 yt-dlp"自动升级）
- ffmpeg*.exe    音视频合并/转换工具
- python         内置 Python 运行库（程序本体的一部分，请勿删除）
- deno.exe       需要 JS 运行时的站点使用（已内置）
- cookies.txt    Cookie 文件（由"获取Cookie"自动生成；抖音下载不需要）
- dy_ttwid.json  抖音访问凭证缓存（自动生成，无需处理）
- wxchannels_engine  微信视频号下载引擎（首次使用"安装/更新视频号引擎"时自动下载）
- ytdlp_gui.py   本软件的源代码
- xxdown_cli.py    命令行接口，供本地脚本 / agent 调用（见上文）
- xxdown_index.jsonl · xxdown_archive.txt   下载记录（自动生成，用于避免重复下载）
- launcher.c     启动器源码（XX Down.exe 由它编译而来）
- build/         打包工具（build_exe.py + Inno Setup 脚本）
